# Scientific validation

No independent fire perimeter or incident dataset was supplied or used; these outputs measure internal descriptive agreement and method behavior, not detection accuracy. USGS publishes candidate resources, including [wildfire perimeter guidance](https://www.usgs.gov/faqs/where-can-i-find-wildfire-perimeter-data) and [a 2023 Kula perimeter map](https://landslides.usgs.gov/static/landslides-realtime/fires/20230808_kula/image.pdf). These have not been ingested, checked for independent derivation, geographic completeness or temporal alignment. Burned-area perimeters are not automatic pixel-level active-fire ground truth. Coverage and cloud/overpass observations are unavailable. The 2023 holdout is not fully blinded because aggregate 2023 ingestion counts were visible before freeze.
