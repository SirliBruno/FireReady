# Architecture

A static Vite React application uses hash routes for the introduction, seven analytical experiences and presentation guide. MapLibre uses the OpenFreeMap Liberty style and built-in attribution; availability requires an external network and WebGL. The UI uses reusable panels and a global React data context backed by `src/services/repository.ts`. Zod validates the limited monthly aggregate contract before rendering it. Real mode defaults to an empty state, while a separate reproducible synthetic file is explicitly selectable and visibly marked across routes. A review record is a human assertion; it does not establish authenticity by itself.

The seasonal chart renders only validated monthly aggregate records. Scientific map overlays, real CSV/GeoJSON ingestion, matching, optimizer, inventory management, synchronized sensor maps and feature selection remain unimplemented. The simulator is configured interactively but its solver is disabled. `src/contracts.ts`, `schemas/`, and `pipeline/` are future interfaces, not a finished pipeline. Source components remain partly centralized in App.tsx and should be split as functionality grows. No backend or authentication is required.
## Sprint 02 addition

The Python pipeline, configured through `config/maui.json`, supports documented FIRMS-like CSV and safe ZIP inputs and exports Parquet, reports, an ingestion manifest and GeoJSON. Runtime source review must precede publishing; the frontend consumes sanitized outputs, never raw CSV. The Data Manager displays selected manifest fields, and MapLibre can display and inspect validated MODIS/VIIRS points in real reviewed mode. The harmonized layer remains unavailable. See `docs/data_ingestion_guide.md` and `docs/data_validation_rules.md` for actual behavior and limitations.
