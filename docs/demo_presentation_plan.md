# Demo presentation plan
1. Introduce the preparedness problem and the Maui case respectfully.
2. Show the study area and explain unavailable datasets honestly.
3. Explain the sensors and the planned harmonization workflow.
4. Explain historical activity versus forecast risk and the held-out test period.
5. Configure hypothetical resources; explain that optimization is unavailable.
6. End with official sources, assumptions, limitations and next steps.

Do not present planned methods or hypothetical inputs as completed scientific findings.
