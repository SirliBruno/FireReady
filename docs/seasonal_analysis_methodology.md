# Seasonal analysis methodology

See [Sprint 04 report](sprint_04_report.md) for results, limitations and reproducibility. The implemented unit is a distinct `(partition, 1 km reference cell, Pacific/Honolulu local date)` with at least one reference-cohort detection. It is reconstructed from the individual UTC timestamps; partitions remain assigned in UTC. It is not the pre-existing UTC cell-day and is not a confirmed fire. Missing coverage is unknown, not zero. No coverage-adjusted rate or fire probability is estimated.
