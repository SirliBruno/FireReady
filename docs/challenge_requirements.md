# Verified challenge requirements

The official 2026 challenge asks for a web application that harmonizes MODIS and VIIRS active-fire hotspot records into a burning activity calendar for a selected area of interest, enabling users to examine historical fire patterns, unusual conditions, and critical periods.

Source: https://www.spaceappschallenge.org/2026/find-a-team/0000-qabas/ (official team page reproducing the challenge description). The challenge page https://www.spaceappschallenge.org/2026/challenges/modis-and-viirs-hot-spots/ returned an error on the latest direct retrieval; review the full page before submission.

The five judging criteria listed on an official 2026 event page are Impact, Creativity, Validity, Relevance, and Presentation: https://www.spaceappschallenge.org/2026/local-events/ajmer/

Event-specific submission rules and the full challenge details still require review. FireReady's resource allocation simulation is the team's proposed extension, not an independently verified challenge requirement.
