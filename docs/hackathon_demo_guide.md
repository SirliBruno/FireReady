# FireReady — دليل العرض أمام اللجنة

مدة مستهدفة: ٣ دقائق. شغّل الإنتاج محلياً قبل العرض: `npm run build` ثم `npm run preview -- --port 4185`. افتح `http://127.0.0.1:4185/#presentation`.

1. 0:00–0:20 — المشكلة: الموارد محدودة والحوادث قد تتزامن.
2. 0:20–0:40 — قصة ماوي: منظومة الاستعداد والتنسيق، دون نسبة المأساة إلى سبب واحد.
3. 0:40–1:00 — MODIS وVIIRS: الدقة الاسمية مختلفة، والمشاهدة ليست حريقاً مستقلاً.
4. 1:00–1:20 — توحيد الرصد: افتح الرصد الموحّد في الخريطة الفعلية.
5. 1:20–1:40 — التاريخ: غيّر الشهر واذكر ضعف التغطية وتفضيل نقطة البداية السنوية في مقارنة ماوي الحالية.
6. 1:40–2:10 — الحل: اضغط «جرّب سيناريو توضيحي». تُحسب النتائج الآن: أغسطس، ٣ مركبات افتراضية، ١٠ كم مسافة مباشرة.
7. 2:10–2:40 — النتائج: بدّل المرجعي والمقترح، ثم أضف حادثين أو أكثر من الخريطة أو قائمة الخلايا. كل حادث يحتاج مركبة واحدة، والمركبة لا تُسند مرتين. أظهر الحوادث غير المخدومة، ولا تفترض أن المحسن دائماً يخدم حوادث عشوائية أكثر.
8. 2:40–3:00 — الأثر والقيود: دعم نقاش الاستعداد، مع الحاجة لبيانات الطرق والجرد والتحقق التشغيلي.

استخدم السابق/التالي أو سهم اليسار للتقدم وسهم اليمين للرجوع. أول تحميل لخرائط الأقمار يحتاج الإنترنت؛ محاكي الموارد يستخدم حدوداً محلية افتراضياً. لا تعتمد على تشغيل نسخ متعددة من خادم التطوير. لا تعلن نتيجة ثابتة إذا تغيرت الميزانية أو النطاق أو النموذج. لا تستخدم نسبة التغطية بوصفها احتمال حريق أو أرواحاً منقذة.
