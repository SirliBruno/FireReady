# Regional data sufficiency — final prototype

Only Maui has a functioning source cohort, configured boundary, harmonization and planning experience. The reference includes 1,146 observations and 333 observed cells. A separate complete land grid now has 2,039 positive-area cells; this prevents treating the observed-only grid as all eligible land, but does not establish observation coverage.

Coverage opportunities, clouds and continuous temporal coverage are unknown. Historical evidence for operational cell-month priorities is not established. The annual/monthly demand proxies and simultaneous-incident scenarios are explicitly exploratory. Counts, exclusions, local-day definitions and held-out exposure are documented in [the final report](sprint_06_final_report.md). No arbitrary sufficiency threshold is presented as scientifically validated.
