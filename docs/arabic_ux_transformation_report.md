# تقرير تحويل تجربة FireReady العربية

## ما نُفّذ

- تعريب التنقل والصفحات الأساسية والخرائط وعناصر التحكم ورسائل الحالات الرئيسية ودليل العرض، مع لغة المستند العربية واتجاه RTL، ووضع الشريط الجانبي على اليمين وتكييفه للجوال.
- إعادة ترتيب التنقل وفق أهداف المستخدم، مع إبقاء إدارة البيانات والمنهجية والعرض متاحة. أضيف رابط «كيف يعمل النظام؟» ومخطط الخطوات الست، مع توضيح المراحل المخططة.
- اعتماد واجهة داكنة متناسقة وأسطح واضحة وخط IBM Plex Sans Arabic عبر Google Fonts مع بديل محلي Tahoma، وأرقام جدوليّة، ورفع حجم النصوص الصغيرة، ومراعاة تقليل الحركة. بقيت الخرائط والمخططات باتجاهها الجغرافي والزمني.
- تقديم الخريطة والتبديل بين MODIS وVIIRS ومناطق الرصد الموحّد، وإخفاء إعدادات الحساسية التفصيلية داخل قسم قابل للفتح، مع إبقاء التحذير من عدم توثيق المصدر مستقلاً ظاهراً. لم تُحذف تفاصيل المصدر والتحقق والقيود.
- صياغة مختصرة لقصة ماوي وربط التحقيق الرسمي؛ توضيح أن الرصد الحراري لا يساوي حوادث فريدة أو احتمال حرائق مستقبلي، وأن المنصة ليست نظام إنذار تشغيلياً.
- إبقاء المحاكاة معطّلة وموسومة كافتراضية لعدم توفر محلّل تحسين أو جرد تشغيلي متحقق منه. لم تُختلق أرقام أو نتائج.

## سلامة العمل العلمي

لم تُعدّل ملفات بيانات NASA الخام أو مسارات المعالجة أو إعدادات المطابقة أو تقسيمات التدريب والاختبار عمداً. بيانات البحث المقدمة لم يُتحقق من مصدرها بشكل مستقل؛ مجموعة NOAA-20 مستبعدة من المرجع بسبب عدم حسم نوع المعالجة. ظهرت ملخصات وصفية لعام 2023 قبل تثبيت الإعدادات، ولم يكتمل تحقق مستقل من الحوادث أو حدود الحرائق. المشاهدات المتاحة لا تثبت حوادث منفصلة.

## التحقق

- `npm test`: نجحت 12 حالة.
- `python -m pytest -q`: نجحت 44 حالة باستخدام البيئة المحلية.
- `npm run build`: نجح بعد تعديلات الواجهة. ظهر تحذير حجم الحزمة.
- `npm run lint`: نجح بعد تعديلات الواجهة.
- اختبار المتصفح الشامل: نجحت 31 من 34 حالة؛ أخفقت ثلاث بسبب محددات الاختبار بعد تغير النصوص وتعدد عناصر التفاصيل. بعد تحديث المحددات نجحت الحالات الثلاث عند إعادة تشغيلها منفردة. لم تُعد تشغيل المجموعة الكاملة بعد هذا التعديل.

## القيود المتبقية

- التعريب غير كامل: قد تظهر نصوص إنجليزية مصدرها بيانات وصفية أو تحذيرات علمية مخزّنة في المخرجات، إضافة إلى أسماء الخريطة ونصوص الإسناد الرسمية. لم تُغيّر هذه المخرجات حفاظاً على المصدر.
- الخط يعتمد على اتصال Google Fonts؛ فشلت محاولة جلب نسخة محلية بسبب عدم توفر الوصول الشبكي للأداة. عند انقطاع الاتصال يُستخدم Tahoma.
- التحليل الموسمي الحالي يعتمد على مجموعة بيانات مجمّعة مراجعة، ولا يحوّل المعاينة البحثية تلقائياً إلى تحليل موسمي. لا توجد بعد خريطة موسمية أو تقويم حراري تفاعلي.
- لا توجد بيانات تشغيلية لمواقع المراكز والجرد أو نموذج تحسين؛ لا تُعرض مقارنات توزيع أو مكاسب مختلقة. لا توجد حالياً صور تاريخية موثقة أو تجربة سرد تمريري كاملة لقصة ماوي.
- يتطلب استكمال التجربة اختباراً بصرياً مباشراً لبقية الصفحات والحالات المفتوحة، واستضافة الخط محلياً، ومراجعة ترجمة الرسائل الديناميكية وتفاصيل إمكانية الوصول، وتقليل حجم حزمة JavaScript. هذه النسخة تحسين عملي وليست تحقيقاً كاملاً لكل معايير التحويل المطلوبة.
